# 采集会话

## 1. 定义

- 定义：一次用户采集任务的关联标识。
- 作用范围：关联前后问卷、设备、采集片段、上传与诊断结果。
- 首页展示三步进度：采集前问卷、数据采集、采集后问卷；设备连接属于数据采集内部步骤，AI 分析不计入该进度。
- 常见代码关键词：`sessionId`、`RouteArgs.SESSION_ID`。

## 5. 首页流程检查点

- 前问卷提交、采集正常结束、后问卷提交分别对应 1/3 至 3/3。
- 首页卡片完成态按各业务实际保存结果独立记录；底部主按钮仍按线性检查点推进，越级完成卡片不会跳过中间流程。
- 回退到前序页面后重复提交已完成的检查点不会降低既有进度或阻塞流程；实际设备连接可用性仍由设备模块确认。
- 应用恢复或硬件中断时保持“待数据采集”业务检查点，但不恢复 BLE 或采集中的瞬态状态；再次进入数据采集时从连接页开始。
- 后问卷提交后返回首页保留 3/3；AI 分析不属于首页流程。
