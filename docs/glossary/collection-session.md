# 采集会话

## 1. 定义

- 定义：一次用户采集任务的关联标识。
- 作用范围：关联前后问卷、设备、采集片段、上传与诊断结果。
- 首页展示四步进度：采集前问卷、连接设备、开始采集、采集后问卷；AI 分析不计入该进度。
- 常见代码关键词：`sessionId`、`RouteArgs.SESSION_ID`。

## 2. 相关位置

| 类型 | 路径/模块 | 说明 |
|---|---|---|
| 路由参数 | `:core:navi` | `RouteArgs.SESSION_ID` 规定跨模块参数名 |
| 业务链路 | feature 模块 | 问卷、设备、采集和分析跳转均接收该参数 |
| 架构证据 | `ARCHITECTURE.md` | 明确列出会话关联范围 |

## 5. 首页流程检查点

- 前问卷提交、设备连接成功、采集正常结束、后问卷提交分别对应 1/4 至 4/4。
- 回退到前序页面后重复提交已完成的检查点不会降低既有进度或阻塞流程；实际设备连接可用性仍由设备模块确认。
- 应用恢复或硬件中断时，设备相关的“可采集”检查点回退到“待连接”，不恢复 BLE 或采集中的瞬态状态。
- 后问卷提交后返回首页保留 4/4；AI 分析不属于首页流程。
